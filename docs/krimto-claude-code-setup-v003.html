02 The two-layer reality — development vs distribution

Two distinct setups. Both required.

The verified data forces a distinction v001 missed: the setup that BUILDS Krimto is a different artifact from the setup that Krimto BECOMES when shipped. obra/superpowers' own CLAUDE.md is 85 lines of contributor guidelines (verified at github.com/obra/superpowers/blob/main/CLAUDE.md) — not development infrastructure. The actual development infrastructure lives elsewhere. Krimto needs both layers, and they have different jobs.

LayerPurposeLives at
Layer A: Development What runs in your terminal while you build Krimto. Subagents, hooks, Superpowers skills, Krimto-specific subagents. Makes 2-3 week ship possible. Your machine + krimto/ repo dev files
Layer B: Distribution What Krimto ships AS. The plugin structure that users install. The marketplace artifact. krimto/ repo — submittable to anthropics/claude-plugins-community
