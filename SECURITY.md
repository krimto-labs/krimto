# Security Policy

## Supported versions

Krimto is pre-1.0 and ships from the `0.2.x` line. Security fixes are applied to the latest
released version.

## Reporting a vulnerability

Please report security issues privately — do **not** open a public GitHub issue.

Email **security@krimto.com** with:

- a description of the issue and its impact,
- steps to reproduce (a proof of concept if you have one),
- the Krimto version (`npx @krimto-labs/krimto status`) and how you're running it (stdio / HTTP / Docker).

We aim to acknowledge reports within 3 business days and to keep you updated as we work on a fix.
Krimto is self-hosted software; there is no managed service in scope.
